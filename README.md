# n8n Job Hunt Automation
An automated job search workflow built in n8n.

# Features
Scrapes job listings
Filters recent jobs
Extracts relevant information
Stores opportunities in Google Sheets
Supports large-scale job searches

# Folder Structure
workflow/ Contains the n8n workflow JSON.

prompts/ System prompts used for extraction.

expressions/ Useful expressions and filters.

sheet-template/ Recommended Google Sheet structure.

# Requirements
n8n, Google Drive, Google Sheet, Openrouter, OpenWebNinja, Apify
